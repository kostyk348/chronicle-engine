# CHANGELOG

Все заметные изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.2.0] — Chronicle Link

### Added — сетевой стол (Chronicle Link)
- P2P-транспорт на чистом `std::net` (Rust): кадры 4-байтовый BE-длина + JSON, предел кадра 16 МБ, keepalive-ping каждые 15 с, корректная обработка обрывов (`src-tauri/src/link.rs`).
- Роли «хост-стол» и «игрок»: хост открывает TCP-порт и ретранслирует, игроки подключаются по `host:port` (локальная сеть или VPN).
- Перенос кампании одним свитком: welcome несёт полный EML-архив кампании, UI предлагает применить его к локальной копии.
- Ростер стола с живыми обновлениями на вход/выход игроков, чат, дедупликация имён суффиксом.
- Честный раунд по commit-reveal: `intent_commit` (SHA-256 канонического JSON интента + сид) до раскрытия, затем `intent_reveal` с проверкой коммита, затем `round_result` со сверкой чексуммы канона между столами.
- Канонический JSON (сортировка ключей) реализован зеркально в Rust и TypeScript и закреплён тестами с обеих сторон — расхождение канона между платформами невозможно.
- Лобби `NetworkLobby.tsx`: хост/join, фазы раунда (Коммит → Раскрытие → Сверка), индикаторы коммитов/раскрытий, детект читерских раскрытий, чат, приём свитка; в браузере панель деградирует в оффлайн-заглушку со схемой протокола.

### Added — WEGO-резолвер v2
- Пятифазный детерминированный раунд: валидация интентов → одновременное перемещение (скорость, рывок ×2, стены и занятые клетки блокируют шаг на последней легальной клетке) → действия → реакции → исход.
- Оружие и заклинания из данных персонажа: кости урона, бонус атаки, диапазон; Палящий луч (лучи по уровню ячейки), Волшебная стрела (автопопадание), Щит (+5 AC как реакция).
- Dodge (помеха атакующим), Help (преимущество союзнику), зелье лечения, попытка побега, правило Fallback для лучей, крик/проза мастера.
- SVG-карта раунда из данных террейна (стены, пропсы, следы, эффекты) и детерминированная художественная проза раунда.

### Added — инфраструктура качества
- CI с двумя джобами: web (tsc → Vitest → Vite build) и rust (cargo test → clippy `-D warnings`) на ubuntu-latest с кешем.
- 26 TypeScript-тестов (Vitest) и 8 Rust-тестов: транспорт, релей коммит→раскрытие между двумя клиентами, welcome-свиток, суффиксы дубликатов, канонический JSON, commit-reveal, автомат фаз, античит.
- MIT LICENSE, CHANGELOG, английский README.en.md, промо-баннер и скриншоты всех шести студий.

### Changed
- Версии синхронизированы: package.json / tauri.conf.json / Cargo.toml → 1.2.0.

## [1.0.0] — Campfire Scribe

### Added
- Нативное десктоп-приложение Tauri 2 + React 19 + TypeScript.
- Архитектура «Zero-Database»: вся кампания в RFC 5322 EML-свитках (`X-TTRPG-*` заголовки, чексуммы SHA-256).
- Тактический бой WEGO v1, криптографические дайсы commit-reveal, издательский цех (EPUB 3.0 / PDF / Typst), аудиоспектакль на Web Audio, EML Vault, листы партии, DM Scribe.

# CHANGELOG

Все заметные изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.6.3] — Hotfix 3: битый EGL на Linux (настоящая причина серого экрана)

Пользовательский лог дал точный диагноз, которого не хватало всем предыдущим флагам: `Could not create default EGL display: EGL_BAD_PARAMETER. Aborting...` — WebProcess WebKit умирает при инициализации EGL и окно остаётся серым, что бы мы ни делали с композитингом.

### Fixed
- На Linux по умолчанию включается `LIBGL_ALWAYS_SOFTWARE=1` — софтверный Mesa-EGL (llvmpipe) поднимается на любой системе, аппаратного ускорения этому интерфейсу не нужно. Отключить (если хочется проверить GPU-путь): `CHRONICLE_FORCE_GPU=1 ./Chronicle.Engine_1.6.3_amd64.AppImage`.

## [1.6.2] — Hotfix 2: полный набор обходных флагов WebKit

### Fixed
- К `WEBKIT_DISABLE_DMABUF_RENDERER=1` добавлен `WEBKIT_DISABLE_COMPOSITING_MODE=1` — бывают драйверы, где одного отключения DMABUF-рендера мало; оба флага зашиты в `main.rs` и ставятся до создания окна.

### Verified
- Фронтенд проверен в headless-браузере на собранном бандле: тактическая карта, панель намерений и все вкладки отрисовываются, ноль ошибок в консоли — серый экран в пакете это рендер WebKitGTK, а не код приложения.

## [1.6.1] — Hotfix: серый экран AppImage на Linux

AppImage 1.5.0/1.6.0 открывался в серое окно на части драйверов — теперь работает из коробки.

### Fixed
- Серый/пустой экран при старте на Linux: WebKitGTK-композитинг через DMABUF падает на NVIDIA и части сборок Mesa. Флаг `WEBKIT_DISABLE_DMABUF_RENDERER=1` зашит в `main.rs` и ставится до создания окна — переменные окружения больше не нужны.
- Релизная сборка macOS: universal-таргет заменён на два нативных джоба — отдельный dmg для Apple Silicon (aarch64) и для Intel (x64); алиас `universal-apple-darwin` в пайплайне так и не завёлся, а нативные таргеты детерминированы.

### Note
- Если интерфейс всё же пуст (редкие виртуалки): `LIBGL_ALWAYS_SOFTWARE=1` — принудительный софтверный GL.

## [1.6.0] — Пометки Мастера и сборки под три ОС

Карта стала по-настоящему общей: не только токены, но и пометки Мастера живут на одном слое у всех столов. А само приложение теперь раздаётся собранными пакетами под все три платформы.

### Added — пометки Мастера в реальном времени
- `Alt+клик` по клетке (режим Мастера) ставит булавку 📍, клик по булавке снимает её; к пометке можно дать подпись, длинная режется до 24 символов.
- Новый вид сообщения `marker` (add/remove) с нормализатором на границе протокола: непустой `marker_id`, клетка внутри поля 16×12 — мусор и чужие клетки отбрасываются.
- Рассылка по diff'у пометок: новые id — add, исчезнувшие — remove, эхо чужих пометок обратно не ретранслируется; приём — мгновенное появление/исчезновение булавки с именем автора в подсказке.

### Added — релизные сборки
- `.github/workflows/release.yml`: матрица раннеров GitHub — Linux (AppImage/deb/rpm), macOS (universal dmg: Intel + Apple Silicon), Windows (MSI/NSIS); официальный `tauri-apps/tauri-action` прикрепляет артефакты к релизу по тегу.
- Ручной запуск с указанием тега доезжает сборками к уже опубликованному релизу.

### Tests
- 80 тестов (69 TypeScript + 11 Rust): `normalizeMarker` — валидные постановки/снятия, обрезка подписи, мусор, границы поля.

## [1.5.0] — Живая карта и импорт листов

Стол перестал быть тремя отдельными мирами: что двигает мастер на своей карте, то видят игроки на своей — в реальном времени.

### Added — живая карта по сети
- Перетаскивание токенов мышью в тактическом виде: мастер двигает любые, игрок — только своего персонажа; стены крипты и занятые живыми клетки блокируют сброс (клетка-цель подсвечивается золотом, недопустимая — красным).
- Новый вид сообщения `token_move` с нормализатором на границе протокола: непустой `entity_id`, целые клетки внутри поля 16×12 — мусор и подделки отбрасываются молча; Rust-ядро пересылает вид без изменений (он и так не фильтрует).
- Эхо-подавление: позиция, только что применённая с чужого стола, обратно не ретранслируется; массовые изменения (>4 сущностей) считаются применённым каноном и `token_move`-флуда не порождают.

### Added — импорт листов D&D Beyond
- `ddbImport.ts`: терпимый парсер JSON — полный экспорт DDB (classes[].definition, stats[] по id, base/bonus/levelUp/override HP, раса объектом) и плоский формат `{name, level, hp, ac, str...}`.
- Производные считаются по правилам 5e, а не копируются: модификаторы характеристик, бонус мастерства, XP до следующего уровня по таблице, ячейки заклинаний для полных заклинателей.
- Всё, что парсер не нашёл, попадает в предупреждения («HP не найдено — принято 8»), а не додумывается молча; мусор отвергается с понятной ошибкой.
- UI: кнопка «Импорт D&D Beyond» в студии партии — вставка из буфера или выбор файла, разбор ошибок и список додуманного до подтверждения.

### Added — джус реплея
- Всплеск частиц на уроне и критах: детерминированный PRNG mulberry32 по номеру кадра — одинаковый раунд взрывается одинаково на любом столе; интенсивность 1..2 (урон ≥15 — ярче, крит/смерть/выпадение в без сознания — максимум).
- Тряска стола на критах и выводе из строя; курсоры grab/grabbing, подсветка активного токена при перетаскивании.

### Tests
- 75 тестов (64 TypeScript + 11 Rust): нормализатор token_move (валид, мусор, границы поля, round по умолчанию), импорт (плоский, DDB-экспорт, недостающие поля, мусор, зажим уровня), частицы (детерминизм, интенсивность) и burst на кадрах (крит/смерть/тяжёлый урон).

## [1.4.0] — Кинематографичный раунд

WEGO-резолвер перестал молчать строками лога: раунд теперь разлагается на машиночитаемые события, и стол проигрывает их как спектакль.

### Added — кинематографичный реплей
- `RoundEvent` в резолвере: `move` (путь и рывок), `attack` (d20, бонус, AC, крит, преимущество/помеха, автопопадание), `damage` (урон, hp после, статус после), `heal`, `note` (щит, уклонение, помощь, побег), `xp`, `outcome`.
- `roundReplay.ts`: чистый таймлайн — кадры с подписями тикера, дугами атак, всплывающими числами урона и изменениями состояния; `applyFrame`/`fastForward` — единственные способы мутации реплей-состояния.
- Тактический стол: токены вынесены в абсолютный слой — движение анимируется CSS-переходом; дуги атак и круги цели рисуются в SVG-оверлее; криты горят золотом, промахи пунктиром. Управление: пауза/плей, покадровый шаг, ×1/×2/×4, мгновенная перемотка, закрытие. Стол заморожен на время показа.
- Реплей открывается сам после каждого разрешённого раунда (и после отправки интента игроком), стартуя со снапшота стола до раунда.

### Added — конструктор интентов и XP
- Визуальный конструктор вместо голого JSON: четыре действия (Заклинание / Атака оружием / Уклонение / Помощь союзнику), выбор оружия из листа персонажа, общая выборка целей (враги — для атаки и магии, союзники — для «Помощи»), путь сбрасывается при смене актёра.
- Честный d20: каждый интент получает свежий случайный `dice_seed` — раньше сид был фиксированным на актёра, и броски повторялись от раунда к раунду.
- XP за павших врагов (`xpValue` из данных, иначе оценка `maxHp*2 + AC*5`) резолвер отдаёт событием, приложение раздаёт его поровну в листы партии сразу после раунда.

### Tests
- 62 теста (51 TypeScript + 11 Rust): состав и порядок событий по фазам, детерминизм событий, автопопадание, щит-реакция, XP (xpValue vs оценка, живые враги не дают XP), таймлайн (кадры, крит/промах, автопопадание), применение кадров (зажим hp, иммутабельность, незнакомые id, перемотка).

## [1.3.0] — Живой стол

Сетевой стол перестал быть только «честным словом»: канон боя теперь **применяется** к кампании, а любые броски за столом проходят через commit-reveal кости.

### Added — честные кости через сеть
- Движок формул `diceEngine.ts`: `NdM`, `NdM+K`, `NdMkhN` (оставить старшие — преимущество), `NdMklN` (младшие — помеха); канонизация метки, детерминированный ГПСЧ sfc32/xmur3 из сида, человекочитаемый разбор броска.
- Протокол бросков поверх релея: `dice_commit` (sha256(формула|сид) до броска) → `dice_reveal` (формула, сид, итог, разбор). Каждый стол **пересчитывает бросок из раскрытого сида** и сверяет с коммитом — подмена любого поля ломает проверку и подсвечивается «ПОДМЕНА».
- Панель «Честные кости» в лобби: пресеты (d20, d100, 2d6+3, 4d6kh3, 2d20kl1) и произвольная формула, фиксация и групповое раскрытие своих бросков, журнал бросков с метками «✓ проверен» / «✗ ПОДМЕНА».

### Added — канон применяется
- `canonSync.ts`: диф канона против локальных сущностей (hp, позиции, статусы, незнакомые id) и применение с зажимом hp в `[0, maxHp]`; локально-уникальные сущности не трогаются, чужие не добавляются.
- Карточка «Канон раунда от X» в лобби: показывает, что изменится, и применяет к кампании одним кликом (или отклоняется).
- Канон раунда теперь несёт и **журнал боя**: «Разослать канон» отправляет сущности + mechanicalLogs, у клиентов журнал обновляется вместе с состоянием боя.

### Tests
- 58 тестов: 47 TypeScript (были 31) + 11 Rust. Новые: парсер формул (валид/мусор/границы), детерминизм сид-RNG, kh/kl семантика, полная машина commit-reveal бросков с пятью сценариями подмены, диф/применение канона (зажим hp, локальная уникальность, чужой статус не рушит тип).

## [1.2.1] — оттачивание Link

### Fixed — сетевой стол
- **Машина честного раунда доведена до конца**: свои коммит/раскрытие/канон теперь попадают в локальное состояние раунда (`NetworkLobby`), эхо хоста больше не дублирует реплики — фазы «Коммит → Раскрытие → Сверка» реально завершаются у всех участников, а не только в тестах.
- **Гонка дедупликации имён устранена**: проверка суффикса, лимит стола и регистрация пира выполняются под одним локом — два «Елены» в один момент больше не затирают каналы друг друга.
- **Молчаливо отвалившийся пир вычищается**: keepalive заметил мёртвый канал исходящих — игрок снят со стола, ростер обновлён у всех (раньше «висяк» жил в ростере вечно).
- **Разошедшиеся каноны видны**: при расхождении чексумм `round_result` стол показывает явное предупреждение о split-brain вместо молчаливого «канона нет».
- **Сортировка ключей канона по кодовым точкам** в TypeScript: астральные символы (эмодзи в ключах) теперь дают побайтово тот же порядок, что и `keys.sort()` в Rust — закреплено тестом на паре «😀 против U+FFFF».

### Added
- Хост видит и копирует адрес приглашения `IP:порт` — локальный IP определяется UDP-трюком без единого пакета (`local_lan_ip`).
- Лимит стола: 12 игроков максимум, 13-й получает явный error-кадр вместо тихого зависания.
- Хост подписывает broadcast своим настоящим именем — в чате у игроков «Мастер», а не безликий «host».
- Конверты `error` от хоста («стол полон», «несовпадение протокола») попадают в журнал стола игрока.
- Подписка на события Link больше не течёт: отписка срабатывает даже если компонент размонтировался до завершения подписки.

### Tests
- 42 теста: 31 TypeScript (были 26) + 11 Rust (были 8). Новые: лимит стола (13-й клиент отклонён), имя хоста в broadcast, вычистка молчаливо умершего пира keepalive'ом, астральные ключи канона, незамерзание фаз, консенсус из трёх столов (split-brain), канон до раскрытий игнорируется.

## [1.2.0] — Chronicle Link

### Added — сетевой стол (Chronicle Link)
- P2P-транспорт на чистом `std::net` (Rust): кадры 4-байтовый BE-длина + JSON, предел кадра 16 МБ, keepalive-ping каждые 15 с, корректная обработка обрывов (`src-tauri/src/link.rs`).
- Роли «хост-стол» и «игрок»: хост открывает TCP-порт и ретранслирует, игроки подключаются по `host:port` (локальная сеть или VPN).
- Перенос кампании одним свитком: welcome несёт полный EML-архив кампании, UI предлагает применить его к локальной копии.
- Ростер стола с живыми обновлениями на вход/выход игроков, чат, дедупликация имён суффиксом.
- Честный раунд по commit-reveal: `intent_commit` (SHA-256 канонического JSON интента + сид) до раскрытия, затем `intent_reveal` с проверкой коммита, затем `round_result` со сверкой чексуммы канона между столами.
- Канонический JSON (сортировка ключей) реализован зеркально в Rust и TypeScript и закреплён тестами с обеих сторон — расхождение канона между платформами невозможно.
- Лобби `NetworkLobby.tsx`: хост/join, фазы раунда (Коммит → Раскрытие → Сверка), индикаторы коммитов/раскрытий, детект читерских раскрытий, чат, приём свитка; в браузере панель деградирует в оффлайн-заглушку со схемой протокола.

### Added — WEGO-резолвер v2
- Пятифазный детерминированный раунд: валидация интентов → одновременное перемещение (скорость, рывок ×2, стены и занятые клетки блокируют шаг на последней легальной клетке) → действия → реакции → исход.
- Оружие и заклинания из данных персонажа: кости урона, бонус атаки, диапазон; Палящий луч (лучи по уровню ячейки), Волшебная стрела (автопопадание), Щит (+5 AC как реакция).
- Dodge (помеха атакующим), Help (преимущество союзнику), зелье лечения, попытка побега, правило Fallback для лучей, крик/проза мастера.
- SVG-карта раунда из данных террейна (стены, пропсы, следы, эффекты) и детерминированная художественная проза раунда.

### Added — инфраструктура качества
- CI с двумя джобами: web (tsc → Vitest → Vite build) и rust (cargo test → clippy `-D warnings`) на ubuntu-latest с кешем.
- 26 TypeScript-тестов (Vitest) и 8 Rust-тестов: транспорт, релей коммит→раскрытие между двумя клиентами, welcome-свиток, суффиксы дубликатов, канонический JSON, commit-reveal, автомат фаз, античит.
- MIT LICENSE, CHANGELOG, английский README.en.md, промо-баннер и скриншоты всех шести студий.

### Changed
- Версии синхронизированы: package.json / tauri.conf.json / Cargo.toml → 1.2.0.
